# Islamic Extension

## Description
The Islamic Extension provides essential Islamic utilities for Muslim users, including prayer times, Quran verses, and nasheeds. The extension automatically adapts to the user's system language, supporting both English and Arabic interfaces.

## Features
- **Prayer Times**: Get accurate prayer times for different countries
- **Quran Verses**: Receive notifications with Quranic verses throughout the day
- **Nasheeds Player**: Listen to Islamic nasheeds anytime
- **Multi-language Support**: Automatic language detection and translation

## Permissions
- Storage: To save user preferences
- Notifications: To display Quran verses
- Alarms: To schedule verse notifications
- i18n: To support multiple languages

## How to Use
1. Select your country from the dropdown menu
2. Click "Get Prayer Times" to view today's prayer schedule
3. Access nasheeds through the options page
4. Receive Quran verse notifications hourly

## Privacy Policy
This extension does not collect, store, or transmit any personal information. All data processing happens locally on your device.
